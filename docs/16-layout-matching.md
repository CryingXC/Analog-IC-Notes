# 16 · Layout Matching

Analog layout preserves assumptions made by the schematic.

## Common-centroid

Useful when matched devices must reject linear process gradients.

## Interdigitation

Distributes fingers of matched devices spatially to average gradients.

## Dummy devices

Reduce edge-condition asymmetry.

## Symmetry

Matched signal paths should see similar:
- routing length;
- parasitic capacitance;
- metal environment;
- contacts / vias;
- well proximity;
- stress.

## High-current devices

Also check:
- current density;
- metal resistance;
- electromigration;
- via arrays;
- thermal gradients.
