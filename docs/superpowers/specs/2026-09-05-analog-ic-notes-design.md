# Analog IC Notes Design

## Goal
Create a public, process-independent analog IC knowledge repository that reflects analog/mixed-signal IC as the current primary technical focus.

## Information architecture
The repository follows a device-to-system progression:
device physics → small-signal model → primitive blocks → amplifiers → frequency response → feedback / stability → noise / mismatch → mixed-signal blocks → layout / simulation.

## Boundaries
This repository must not become a duplicate of `Analog-Tapeout-Workflow`. It explains circuit and device concepts; implementation signoff details remain in the tape-out repository.

## Public-release rules
No foundry PDK, model card, rule deck, techfile, GDS/OASIS, extracted production netlist, private infrastructure detail, or restricted screenshot.

## Tone
Technical, compact, derivation-oriented, and useful as an engineering notebook rather than a beginner textbook.
