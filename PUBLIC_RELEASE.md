# Public Release Policy

This is a public educational repository.

Do not commit:
- PDKs or model cards;
- proprietary device libraries;
- Calibre / DRC / LVS / PEX rule decks;
- techfiles / layer maps;
- GDS / OASIS;
- extracted production netlists;
- private server paths, credentials, licenses, or infrastructure details;
- restricted screenshots.

The notes are intentionally process-independent. Process-specific design rules and device parameters must come from authorized documentation.
